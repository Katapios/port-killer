# 🚀 Port Killer

Кроссплатформенная CLI-утилита на Go для быстрого сканирования портов, просмотра подробной информации о процессах (PID, имя, пользователь, протокол) и интерактивного завершения выбранных процессов для освобождения портов.

---

## 🛠 Технологии

* **Go** (стандартная библиотека + `text/tabwriter`)
* **[Charmbracelet Huh](https://github.com/charmbracelet/huh)** — интерактивный консольный интерфейс (мультивыбор и подтверждения).

---

## 📋 Системные требования

* **Linux / macOS:** Требуется установленная утилита `lsof`.
  * *Ubuntu / Debian:* `sudo apt install lsof`
  * *macOS:* предустановлена по умолчанию (или `brew install lsof`)
* **Windows:** Не требует сторонних утилит (использует встроенные `netstat` и `tasklist`).

---

## 📦 Установка и сборка

1. Убедитесь, что у вас установлен **Go** (версии 1.18 или выше).
2. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone [https://github.com/ВАШ_ПОЛЬЗОВАТЕЛЬ/port-killer.git](https://github.com/ВАШ_ПОЛЬЗОВАТЕЛЬ/port-killer.git)
   cd port-killer

3.Инициализируйте зависимости и соберите проект:
go mod tidy
go build -o port-killer main.go

🚀 Запуск
​Для корректного отображения всех системных процессов рекомендуется запускать утилиту с повышенными привилегиями:

Linux / macOS:
sudo ./port-killer
Windows:
Запустите командную строку или PowerShell от имени Администратора и выполните:
.\port-killer.exe
Использование:
​Утилита автоматически отсканирует систему и выведет таблицу активных процессов, прослушивающих порты.
​С помощью стрелочек перемещайтесь по списку, а клавишей Пробел выберите один или несколько процессов для завершения.
​Нажмите Enter, подтвердите действие, и выбранные процессы будут завершены, мгновенно освободив порты.
